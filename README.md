# Nexus ERP

> A comprehensive **Enterprise Resource Planning** system that unifies business operations — from inventory and HR to finance and procurement — into a single, cohesive platform.

🌐 **Live Demo:** [Nexus-ERP on GitHub Pages](https://pinnacleroute.github.io/Nexus-ERP)

---

## ✨ Features

- 📦 Inventory & warehouse management
- 👥 HR & employee records
- 💰 Finance & accounts module
- 🛝 Procurement & vendor management
- 📊 Real-time reporting dashboard
- 📱 Fully responsive UI
